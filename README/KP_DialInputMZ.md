# KP_DialInputMZ
# ダイヤル式文字列・絵文字入力 v1.0.0
RPGツクールMZの「数値入力の処理」の代わりに、ダイヤルを回して文字列や絵文字を入力するプラグインです。<br>

![サンプル](../gif/KP_DialInputMZ_sample01.gif)<br>

# [ダウンロード](../Plugin/KP_DialInputMZ.js)<br>


# 導入手順

1. `KP_DialInputMZ.js` をダウンロードして `js/plugins/` に入れます。<br>
2. プラグイン管理から有効（ON）にします。<br>


# 使い方
- **パズル全データの登録**：識別名・正解文字列・各桁の候補文字を設定します（候補文字は直接入力、絵文字も可）。<br>
- **プラグインコマンド（文字列入力の開始）**：識別名とウィンドウ背景（0: ウィンドウ / 1: 暗くする / 2: 透明）を指定して呼び出します。<br>
- **正誤判定**：終了後、スクリプトで `puzzle("識別名")` または `puzzle(番号)` を使います。<br>
- **操作**：左右キー／クリックで桁移動、上下キー／ホイール／上下ドラッグで回転、決定キー／中央タップで確定。<br>
