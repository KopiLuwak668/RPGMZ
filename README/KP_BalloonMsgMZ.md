# KP_BalloonMsgMZ
# フキダシメッセージ v1.0.0
RPGツクールMZの「文章の表示」「選択肢の表示」を、キャラクターの頭上や足もとなどに出るフキダシとして表示するプラグインです。<br>

![サンプル](../gif/BalloonMsg_sample01.gif)<br>

# [ダウンロード](../Plugins/KP_BalloonMsgMZ.js)<br>


# 導入手順

1. 上記リンクから `KP_BalloonMsgMZ.js` をダウンロードします。<br>
2. プロジェクトの `js/plugins/` フォルダに入れます。<br>
3. RPGツクールMZのプラグイン管理から有効（ON）にします。<br>


# 使い方
## プラグインパラメータ
なし<br>

<br>

---

## プラグインコマンド

| コマンド名 | 概要 |
| :--- | :--- |
| 吹き出しモード開始（標準） | 対象キャラクターとテールの有無だけを指定し、初期設定でフキダシ表示を始めます |
| 吹き出しモード開始（詳細） | 表示位置・ずらし量・文字装飾・サイズ・選択肢・カメラ・SEなどを細かく指定して始めます |
| 吹き出しモード終了 | イベント途中で通常のメッセージウィンドウに戻します |

<br>

## メモ欄（イベント・マップなど）
なし<br>

## テキストタグ（すべてのウィンドウ）
フキダシに限らず、ウィンドウの文字描画全般で以下のタグが使えます。<br>
「文章の表示」や「文章のスクロール表示」で表示される文字をタグで囲むと、太字や斜体、下線、中央寄せ、右寄せにします。<br>

| タグ | 説明 |
| :--- | :--- |
| `<B></B>` | 太字にします |
| `<I></I>` | 斜体にします |
| `<S></S>` | 下線にします |
| `<rt></rt>` | 右寄せにします |
| `<ct></ct>` | 中央寄せにします |

※タグは大文字・小文字の区別はしません。<br>

<br>

# 見た目のカスタマイズ
フキダシの座布団・テールの色や、選択肢のグラデーション色は、`KP_BalloonMsgMZ.js` コード先頭の `CFG_B` および `CHOICE_STYLE` で変更できます。<br>
