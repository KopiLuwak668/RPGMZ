# KP_InputAlphabet/KP_InputAlphabet.js
RPGツクールMZ向けの「ダイヤル式アルファベット入力」プラグインです。

## 特徴
- カチッと吸い付くような滑らかなアニメーション
- 選択中の文字を大きく、濃い黄色で強調表示
- 複数のパズルを個別の「識別名」で管理可能

## 使い方
プラグイン設定でパズルを登録 * 「パズル全データの登録」という項目を開きます。

好きな名前（例：DoorA）を付けます。

「各桁の候補文字」という項目を桁の数だけ追加します。例えば3桁なら、項目を3つ作ります。

各項目の「候補文字」欄に、その桁で使いたい文字（例：ABCDEFG）を直接入力します。

プラグインコマンドで実行 * イベントコマンドの「プラグインコマンド」から open を選びます。

パズル識別名: 先ほど付けた名前（例：DoorA）を入れます。

格納変数ID: 入力結果（文字列）を保存したい変数（例：1）を選びます。

イベントでの正誤判定 * 「条件分岐」のスクリプト欄に $gameVariables.value(1) === "ABC" のように書いて、正解かどうかを判定します。
