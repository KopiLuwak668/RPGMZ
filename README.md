# KopiLuwak's RPG Maker MZ Plugins

RPGツクールMZ向けの自作プラグインを公開しているリポジトリです。

## プラグイン一覧 (Index)

| プラグイン名 | 特徴 |
| :--- | :--- | 
| [KP_InputAlphabetMZ](https://github.com/KopiLuwak668/RPGMZ/blob/main/ReadMe/KP_InputAlphabet.md) | 数値入力の仕組みでアルファベットを扱えます。識別名で個別管理が可能です。 |
|[KP_BalloonMsgMZ]([https://github.com/KopiLuwak668/RPGMZ/blob/main/](https://github.com/KopiLuwak668/RPGMZ/blob/main/KP_BalloonMsgMZ.js))|キャラクターに吹き出しを表示するプラグインです。|
| **KP_LightsOutMZ** | | 定番の消灯パズル。こちらも識別名による独立管理に対応しています。 |
